# 首页第四策略：60 日风险调整动量

策略 ID `momentum_60`，首页短名“60 日动量”，引擎 `shortline-1.3.0`。按用户要求作为研究观察选项加入首页，排在流动性趋势、缩量回踩和黄金坑之后。

## 胜率依据

在本轮八个新候选共同计算的两个阶段中，它的胜率均最高。开发期（2025-05 至 12 月）合并平仓胜率 44.27%、三个账户平均收益 -6.34%；选择期（2026-01 至 04 月）合计 306 笔平仓、胜率 48.69%、账户平均收益 +1.99%。三个换仓起点各使用独立 10 万元账户，主检验持有 3 日，计入费用、滑点、整手与现金约束。数字来自 [封存结果](../research/reports/20260905/development.csv)。

该策略未通过此前的完整准入门槛，也未进行自己的独立留出检验。本次是用户指定加入观察，不能据此宣称已验证盈利或未来胜率 48.69%。此前报告和封存选择保持不变。App 动态历史页面另做事后事件研究，不能与上述资金账本口径混用。

## 选股规则

1. 沪深主板（00xxxx.SZ、60xxxx.SH），当前非 ST / 退市名称；至少 80 根日线，最近 60 个市场交易日连续；价格 ≥3 元，20 日均成交额 ≥1 亿，ATR14/价格 ≤6%，有成交；信号日复权因子和实际上下限价格有效。
2. 在当天主板基础池中，按 20 日均成交额取前 40%，向上取整；同额按代码排序。
3. 收盘高于 MA60，60 日连续价格收益为正，当日涨幅 ≤5%。不额外增加 MA20、市场宽度、行业限额或其他择时门槛。
4. 以 `ret60 / vol60` 排序。`ret60` 为 60 日连续价格收益，`vol60` 为近 60 个每日收益的样本标准差（ddof=1）。原始比值降序、同值代码升序，精选最多 5 只，不设行业限额。
5. UI 的 0–100 排序分只是满足趋势与流动性条件的候选池内百分位；Top5 始终按未取整的原始比值确定。符合全部条件但未进前 5 的显示“符合”；其他条件满足、但当日涨幅超过 5% 的显示“等待”。市场宽度仅是环境参考。
6. 盘后生成信号，次日开盘观察；高开超过 3%、涨停、停牌或约束不足时留现金、不以第 6 名补位。MA60 是趋势参考，近五日低点/1.5 ATR 只是显示的失效参考，并未当作盘中止损加入历史检验。

## 两端与发布

Mac 与 iOS 共用 `Models.swift` 中的策略顺序、说明和可选字段 `vol60` / `momentumRatio`。旧三策略报告仍可解码；四策略报告各自缓存，图表继续绑定同一行情版本。

服务器和 Mac 后台节点使用同一份 `engine/momentum.py`。重新选股/更新行情生成四套完整报告：同 as_of、data_revision、股票集合和逐字节相同的 K 线，校验通过才切换 current。需要先确认队列和上传为空，再同步升级两端 worker/API；三策略旧 worker 与四策略新 ingest 不可混跑。尾盘两套策略及 Bark 设置属于原独立流程。

历史 App 事件页面使用当前名称过滤，不拥有完整逐日状态；原研究的逐日 ST 和真实资金账本在独立研究目录，未改写为 App 的事件数据。

## 验证范围

新测试比较 App 规则与研究规则的 Top5，覆盖未来数据不改变旧排名、同一行业可保留 5 只、原始比值控制排序、主板限制、约束缺失拒绝及超过 5% 的等待状态。发布测试覆盖第四报告/图表损坏不能替换 current、缺第四报告的上传拒绝、旧三策略 API 仍可读取；Swift 检查四套报告解码和缓存共存。

最新 2026-09-04 实际 Top5 与封存面板的当日 `pick_momentum_60` 完全一致。软件功能与策略盈利证据分别验收。
