# JEV 实时候选买入判断

2026-09-21。TypeSafe 官方文档：https://docs.typesafe.ai/api 、https://docs.typesafe.ai/concepts/system-one 、https://docs.typesafe.ai/models 。

固定 HTTPS `POST https://api.typesafe.ai/v1/systemone`，Bearer 鉴权，固定模型 `jev-1.13.0`。不用Python SDK（Mac运行时为Python3.9），无新增依赖。JEV只返回Choice/Score/Noul，不生成研报；当前使用两个Choice，输出买入倾向与依据类别。置信度是分类把握度，不是股票盈利概率，也未经本股票样本校准。

## 输入和结果

- 覆盖已完成的一夜持股、黄金半小时、底部放量、大单承接；同一轮次同股合并，最多40只。同股行情冲突则观望。
- 仅发送冻结的公开报价、量价指标、触发/待核查条件和源时间。白名单不含账户持仓、服务器凭据、Bark或DeepSeek Key。
- 英文问题明确引用候选索引/代码；state包括中文规则、数值单位、1–5交易日研究范围。没有联网核查新闻或财报，不能让模型假称已完成核查。
- 原始分类 buy/watch/avoid 与依据分类独立返回。分类/依据冲突、分类置信度低于0.7，或buy依据把握度低于0.55时，应用转为观望；原始分类与概率分布仍保留。
- 支持考虑买入仍须人工确认最新价格、公告和可成交性；不设置自动下单或自动交易。

## 时间和存储

JEV异步线程在服务器读取已发布的Mac/备用服务器筛选快照，不另行登录达塔。原筛选/Bark不等待JEV。源报价超过180秒后只作回看。结果推送绑定源报价的绝对expires_at，正文写明源时间与有效截止；发送前再次检查，设备延迟收取时App也显示过期。

原始run-archive不改写。JEV判断单独存放于jev-reviews，以输入SHA-256、规则/问题SHA-256、模型版本、request_id、判断时间定位；每次完成的尝试另存不可覆盖副本。通知绑定具体request_id，手动重分析不改掉旧通知对应的判断。保留1000个轮次结果/尝试，手动待处理队列上限20。

pending/running先持久化再外呼；进程中断的running不会自动重发，避免不确定的重复计费。队列坏项单独隔离，启动/周期恢复遗漏的排队记录。HTTP限流/错误/超时保留原提醒，可手动重试，不自动无限重试。

## 设置和接口

`POST /v1/realtime/settings` 增加jev_enabled、jev_key、clear_jev；公开设置只返回jev_enabled与jev_configured。Key保存在服务器原有受限配置文件，不嵌入App/Git或放入URL。设置和请求绑定持久代际，清除后旧orphan不会被新Key复活；判断记录有独立完整性哈希。修改JEV配置与外呼通过独立锁串行：停用/清Key完成后不再启动旧Key请求；已发起请求无法撤回。该锁不阻塞原推送与市场筛选。

`POST /v1/realtime/jev {"slot":"..."}` 显式分析某轮快照（包括历史回看），每轮至少间隔60秒。最新/历史/通知详情可附加jev结果和逐股jev字段；旧客户端忽略可选字段。

## 验证

官方模型列表鉴权HTTP200；使用真实2026-09-21 14:50两只候选完成一次API调用，返回jev-1.13.0。因为接入时已收盘，严格标为historical，不发送买入提醒。测试覆盖过期、原始归档不可变、四策略合并、分类冲突、旧请求回写、清Key与外呼互斥、队列恢复、原始通知绑定和密钥不回传。盈利效果尚待后续独立观察。
