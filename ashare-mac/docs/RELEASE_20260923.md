# 观澜合并版本 · 2026-09-23

合并 `cursor/ios-open-tonghuashun-21ab` 与 `cursor/perf-sync-color-publish-f732`。Mac 1.14.0（18），iOS 1.13.0（18）。iPhone 个股详情及K线增加由用户点击触发的同花顺跳转，仅接受六位A股代码和SH/SZ/BJ后缀；未安装同花顺时显示本地提示。

同步优化包含短列表、逐股条件明细、服务器内容版本、共用全市场K线、搜索输入延迟过滤和涨跌颜色。兼容旧版手机的五项条件布尔字段保留；入选股保留完整技术证据供盘后JEV。五策略和全市场K线作为一个完整版本发布，逐股明细须一一对应并与报告内容一致，失败时保留先前版本。Mac和iOS详情按版本读取明细，读取失败时显示待核验。每日总结、实时状态和JEV的内容变化均可触发客户端刷新。

测试：417项后端测试通过；合并后全套产品缓存、通知、图表和同花顺链接测试通过；Mac及iOS无签名真机架构编译通过。用2026-09-21本地完整行情独立试打包：5,620只股票、五策略、39,357个ZIP成员、221.9MiB；经服务器同款extract验证用时34.9秒，39只去重精选均有JEV技术指标。该试跑仅验证包格式，不替换正式行情或策略收益记录。
