# 2026-09-08 实时结果未送达的原因与修复

行情与计算子进程返回 ready，父进程随后提交失败，并成功提交了较小的 blocked 回退报告。问题发生在 Nginx，请求尚未进入 Python 业务校验。

## 证据

Nginx 全局 `client_max_body_size 1k`，仅大文件行情上传配置例外，实时结果提交没有例外。错误日志记录以下请求体被拒绝（服务器记录的北京时间）：

| 轮次 | 请求字节 | 结果 |
|---|---:|---|
| 09-08 14:30:55 | 10,907 | 请求体过大 |
| 09-08 14:33:50 手动检查 | 10,982 | 请求体过大 |
| 09-08 14:45:34 | 9,923 | 请求体过大 |
| 09-08 14:50:41 | 10,827 | 请求体过大 |

本机诊断显示 14:45、14:50 计算为 ready，耗时约 30–38 秒；报价覆盖 4,984 / 4,985。由于网关拒绝了完整结果，父进程回退报告约几百字节，反而能够提交，导致界面误称计算未完成。

无效的 2,080 字节诊断请求（不含有效租约与行情报告）也稳定得到 HTTP 413。独立隔离测试中的同形完整报告可序列化、通过业务 `validate_report`，发布体约 11 KB，支持上述因果判断。

## 修复

- 仅对精确路径 `/v1/worker/realtime/publish` 设置 256 KiB 网关上限，与业务入口的外层上限一致。报告内部仍有 128 KiB 校验，普通接口仍为 1 KiB。
- 先备份现网配置，通过 `nginx -t` 后 reload。备份为 `/opt/guanlan-backups/nginx-before-realtime-256k-20260908T194427.conf`。
- 父进程将提交失败单独记录为 publication，保留 HTTP 状态码，不再把 HTTP 413 包装成计算失败。有效计算结果在本机 `computed/` 私有目录保留最近 30 份，不含租约或密钥。
- 小于上限但使用假租约的发布体返回 HTTP 409；相同尺寸的普通接口仍返回 HTTP 413；256 KiB + 1 字节发布体仍返回 HTTP 413。探测不会创建任务、结果或通知。

可复验：`PYTHONPATH=. .venv/bin/python deployment/verify_realtime_gateway.py --config settings/mobile-worker.json`。私有配置仅通过文件读取。
