# 观澜选股 · macOS

## 目标与授权
为本机用户构建一个可双击启动的中文原生 Mac 短线选股应用。在 quanta 根目录的 ashare-mac 新建工程，只读现有行情数据，策略和代码从头设计。用户已授权实现和自主策略设计，并明确持有 1–5 个交易日；常规实现选择直接推进。

## 产品与技术
SwiftUI + AppKit 原生窗口，Python 3.9+ / pandas 2.3.3 / numpy 2.0.2 / pyarrow 21.0.0 本地研究引擎。无服务器、无账号。支持候选筛选、股票搜索、K 线及均线、入选理由、观察列表、CSV 导出、历史检验、数据质量及数据目录设置。加载、空列表、失败均有可恢复状态。默认目录 ../data；重新选股重读本地文件。

用户追加授权：使用本地 ProMax 接口补齐数据，并在新工程实现更新接口。独立 ProMax 客户端按现有文档使用 HTTPS GET /tushare/pro/{api_name}，Keychain 服务 quanta.promax.api-key 或 PROMAX_API_KEY 环境变量，X-API-Key 头。仅请求行情日期及代码，不发送本地数据。更新日线、复权因子、涨跌停价、交易日历、当前股票列表；补近期缺口，校验跨表代码覆盖、日期、唯一性、价格后逐日原子发布到新工程 data/updates。失败日不发布，可重试；之前有效日期保留。应用显示更新进度、最后错误，更新完成自动重算。

## 策略：趋势回踩后的转强 v1
固定规则，默认 3 个交易日，同时报告 1/3/5 日信号表现。信号仅使用截至当天的 OHLCV。使用 close/pre_close 构建连续价格指数，避免直接跨除权比较原始价格；复权因子用于独立检验收益计算。连续价格并非独立核验的官方前复权。

基础池：沪深 A 股、当前名称非 ST/退、至少 80 根日线、连续 60 个市场交易日有效行情、20 日平均成交额 >= 1 亿元、收盘 >= 3 元、日 ATR/价格 <= 6%。当前名称缺少历史快照，存在幸存者及历史 ST 状态偏差。

观察条件：收盘 > MA20 > MA60、MA20 高于 5 日前、20 日相对强度位于基础池前 35%、距离 10 日最高价回撤 1%–10%、过去 3 日平均成交额/20 日平均成交额 <= 0.95、收盘距 MA20 在 0–8%、单日涨幅 -1%–5%。当天收盘高于前收且收盘位置 >= 55% 为转强确认。市场宽度为基础池中位于 MA20 上方的比例；低于 40% 暂停新候选。评分只衡量匹配程度，不是获利概率。

评分：相对强度 30、趋势 20、回踩位置 20、量能收缩 15、低波动 15，总分 0–100。不可为了凑 Top10 放松硬条件。备选观察和已确认分列，数据缺失标明并排除。

历史检验：按市场交易日 D 收盘信号，D+1 开盘进入，D+1+h 开盘退出（h=1/3/5），满足 T+1。信号日、进入日及退出路径需要复权因子与实际涨跌停价。开盘触及涨停不可买，跌停不可卖；已知跌停最多顺延 5 个市场日，仍无法退出标记未结算，观察窗未结束标记截尾。缺失行情或复权/限制价单列 missing_exit，不能当作已知停牌后顺延成功。缺数保留失败数量。买入开盘相对除权参考前收高开 >3% 放弃。收益以复权因子比率校正，扣固定往返 30bp，并报告 60bp 压力成本。每日最多 10 个确认信号、同当前行业最多 2 个。等权信号事件研究，样本会重叠；不计算虚假的可交易组合净值、年化或夏普。分月展示而不称为独立样本外。参数预先固定，不调参追逐历史结果。

观察价：前一根最高价为突破观察位、MA20 附近为回踩参考、最近 5 日低点与 1.5 ATR 给出失效参考；仅为盘后计划，跳空/跌停不保证按价成交，回放不模拟盘中止损。

## 目录与命令
- engine/: 独立数据、信号、事件检验及 JSON/CSV 生成
- macos/: SwiftUI 界面及本地进程桥接
- tests/: stdlib unittest 行为测试
- scripts/: 环境、编译与启动
- docs/: 规格、策略、验证证据

```sh
cd /Users/bennie/quanta/ashare-mac
bash scripts/setup.sh
.venv/bin/python -m unittest discover -s tests -v
.venv/bin/python -m engine.cli --data-root ../data --output .cache/analysis
bash scripts/build.sh
open build/观澜选股.app
```

## 风格和测试
Python 类型标注、纯函数优先，snake_case，JSON snake_case；Swift 小型 View 和 Codable 模型，原生系统字体、深青色强调色、A 股红涨绿跌。例：`def features(bars: pd.DataFrame) -> pd.DataFrame:`。
先编写真实约束测试：未来追加不改变过去信号；跨除权收益；重复及无效行情拒绝；T+1；涨停跳过；跌停延迟、未结算保留；成本扣减；非法路径；原子发布失败保留旧快照。实际全量数据生成后校验，编译并启动 .app，真实窗口核对筛选、详情、自选、导出与数据状态。

## 边界和验收
必须：只读源数据；每份输出有日期、版本和覆盖范围；失败保留旧报告；验证测试与真实窗口；所有新增代码仅在本工程。
需要另行授权：接入实盘交易、上传本地数据、删除原工程文件、对外发布。
禁止：继承本地旧策略权重、读取密钥、伪造回测、把不足的证据称作已验证优秀策略。
完成条件：真实本地数据驱动的可启动 .app、可重跑选股、可导出、规则和局限可读、历史检验可复现、测试通过。

## 实现任务
1. 数据与信号切片：读取校验、固定规则、单测、生成真实候选。
2. 检验与报告切片：T+1 事件评估、多周期、成本/失败计数、原子 JSON/CSV。
3. 原生应用切片：三栏选股窗口、K 线、搜索与自选、报告页、目录选择。
4. 交付切片：可重复构建、启动器、实际窗口验证、说明文档和验证结果。
